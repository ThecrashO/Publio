Telegram Bot Configuration
First-Class Platform
Obtained from Telegram @BotFather. Never exposed to browser visitors.
Unique channel ID (e.g. -100xxxxxxxxxx) or public channel handle.
@

  1. Open Telegram and search for @BotFather.
  2. Send /newbot, choose a name and username for your Bot.
  3. Copy the generated HTTP API Token and paste it into the field above.
  4. Add your Bot as an Administrator inside your target Telegram Channel.
  5. Ensure the Bot has administrative permission to Post Messages.
  6. For channel ID, forward a message from your channel to @userinfobot or @RawDataBot to find your -100... ID.
Facebook Page — Setup Guide
Not Connected
From Facebook Developers → Your App → Settings → Basic → App ID

  1. Go to developers.facebook.com/apps and log in with your Facebook account.
  2. Click "Create App" → Choose type "Other" → "Business" → Give it any name (e.g., PostPilot).
  3. Inside the app, go to Settings → Basic. Copy your App ID and paste it into the field above.
  4. Copy your App Secret (click Show) → You'll need to add this to Supabase Secrets.
  5. In the left sidebar, click "Add Product" → Set up Facebook Login for Business.
  6. Go to Facebook Login → Settings → Under "Valid OAuth Redirect URIs", add this URL:
https://chzcqxzebsxiqgxbmurq.supabase.co/functions/v1/oauth-facebook-callback
  1. Click "Save Changes".
  2. In your terminal, run:
npx supabase secrets set FACEBOOK_APP_ID=your_app_id
npx supabase secrets set FACEBOOK_APP_SECRET=your_app_secret
npx supabase secrets set SITE_URL=http://localhost:8080
  1. Paste your App ID above and click "Connect Facebook".
  2. Authorize and you'll be redirected back here with status Connected.
You must have a Facebook Page to publish posts. Personal profiles are not supported by the API.
Instagram Business — Setup Guide
Not Connected

Instagram uses the same Facebook App. If you've already done the Facebook setup, skip to Step 4.
  1. Inside your Facebook App (from Facebook setup above), click "Add Product" → Set up Instagram Graph API.
  2. Go to Facebook Login → Settings → Add this redirect URI:
https://chzcqxzebsxiqgxbmurq.supabase.co/functions/v1/oauth-instagram-callback
  1. Make sure your Instagram account is set to Business or Creator:
    Instagram App → Profile → Settings → Account type → Switch to Professional.
  2. Link your Instagram to a Facebook Page:
    Facebook Page → Settings → Linked Accounts → Instagram → Connect.
  3. Paste the Facebook App ID in the field above and click "Connect Instagram".
  4. Authorize permissions — PostPilot will automatically detect your linked Instagram Business account.
Instagram API does not support personal accounts. Only Business or Creator accounts linked to a Facebook Page can publish posts via API.
LinkedIn Profile — Setup Guide
Not Connected
From LinkedIn Developers → Your App → Auth → Client ID

  1. Go to linkedin.com/developers/apps and sign in.
  2. Click "Create App" → Fill in App Name, LinkedIn Page (create one if needed), and App Logo.
  3. Go to the "Auth" tab. Copy your Client ID and Client Secret.
  4. Under "Authorized Redirect URLs", add:
https://chzcqxzebsxiqgxbmurq.supabase.co/functions/v1/oauth-linkedin-callback
  1. Go to "Products" tab → Request access to:
    • Share on LinkedIn
    • Sign In with LinkedIn using OpenID Connect
  2. In your terminal, run:
npx supabase secrets set LINKEDIN_CLIENT_ID=your_client_id
npx supabase secrets set LINKEDIN_CLIENT_SECRET=your_client_secret
  1. Paste Client ID above and click "Connect LinkedIn".
  2. Authorize on LinkedIn → redirected back with Connected.
X (Twitter) — Setup Guide
Not Connected
From X Developer Portal → Your App → Keys and Tokens → Client ID

  1. Go to developer.twitter.com/portal/dashboard and sign in with your X account.
  2. Click "+ Create Project" → Name it (e.g., PostPilot) → Create an App inside it.
  3. Inside the App, scroll to "User authentication settings" → Click "Set up":
    • OAuth 2.0 → On
    • App type → "Web App, Automated App or Bot"
    • Callback URI / Redirect URL → paste this:
https://chzcqxzebsxiqgxbmurq.supabase.co/functions/v1/oauth-x-callback
  1. Website URL → http://localhost:8080
  2. Click "Save". Now go to "Keys and Tokens" tab.
  3. Under "OAuth 2.0 Client ID and Client Secret" → copy both values.
  4. In your terminal, run:
npx supabase secrets set X_CLIENT_ID=your_client_id
npx supabase secrets set X_CLIENT_SECRET=your_client_secret
  1. Paste Client ID above and click "Connect X".
  2. Authorize on X → redirected back with Connected.
X uses OAuth 2.0 with PKCE — PostPilot automatically generates a secure code challenge. Your credentials are never stored in the browser.
